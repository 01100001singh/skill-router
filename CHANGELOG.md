## [0.1.0] - 2025-01-31

### Added

- Initial release
- Core `SkillVTable` for skill dispatch
- `SkillRegistry` for skill management
- Routing strategies: Semantic, Hybrid, Rule-based
- Encoders: OpenAI, Cohere, HuggingFace, Local
- Skill parser with YAML frontmatter support
- Utterance generator for skill metadata
- Compliance module with audit logging
- Explainability reports
- Claude Code integration
- Example skills: PDF, DOCX, Credit Underwriting
- Comprehensive test suite
- CI/CD with GitHub Actions
